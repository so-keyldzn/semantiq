## Task prompts

- `rg-concept-binary` (conceptual): How does the search library notice that it is reading a non-text file and then either stop or keep going? Which source files implement that heuristic and its configuration?
- `rg-concept-colors` (conceptual): Users can customise how matches, paths and line numbers are highlighted in the output. Which source file parses those user-supplied styling specifications?
- `rg-concept-ignore-decision` (conceptual): When walking a directory tree, where is the final decision made that a given entry should be skipped, combining ignore files, overrides, file types and hidden-file rules? List the source files that implement that combination (not the individual rule parsers).
- `rg-concept-threads` (conceptual): When the user does not ask for a specific degree of parallelism, how does the command-line tool choose how many threads to use, and in which cases does it force a single thread? Name the function that decides.
- `rg-struct-sink-impls` (structural): List the concrete types that implement the searcher's `Sink` trait, excluding tests and the blanket impls for `&mut S` and `Box<S>`.
- `rg-struct-skip-callers` (structural): Who calls the free function `should_skip_entry` in the `ignore` crate? Name the calling functions/methods.
- `rg-exact-max-columns` (exact): In which source file is the `-M/--max-columns` command-line flag defined?
- `sq-concept-calibration` (conceptual): Search results are filtered by a similarity cut-off that can adapt per programming language based on past queries. Which source files collect the past measurements and turn them into per-language cut-offs?
- `sq-concept-exclusions` (conceptual): Third-party dependency folders, hidden directories and oversized files must never end up in the index. Which source file defines these rules?
- `sq-concept-model-integrity` (conceptual): How does the tool make sure the machine-learning model file it fetches from the internet has not been tampered with or corrupted? Name the function(s) that perform the check.
- `sq-concept-path-guard` (conceptual): A client of the server asks to read or analyse a file by path. How is it prevented from reaching files outside the project directory (e.g. with `..`)? List the source files that contain such guards.
- `sq-concept-rename` (conceptual): While the server is running, files get renamed or moved on disk. How does the index avoid keeping stale entries under the old path? Name the function(s) that handle this.
- `sq-concept-upgrade-wipe` (conceptual): After upgrading to a release whose code-extraction logic changed, existing indexes must be wiped and rebuilt from scratch. Which source files contain the check that decides this and the places that run that check at startup?
- `sq-struct-embedding-impls` (structural): Which concrete types implement the `EmbeddingModel` trait?
- `sq-struct-exclude-entry-callers` (structural): Who uses `should_exclude_entry`? List the non-test source files that call it, excluding the file that defines it and plain re-exports.
- `sq-struct-fts-escape` (structural): Trace how user input reaches the FTS5 full-text query: which function calls `escape_fts5_query`, and which functions call that function?
- `sq-struct-impact-exposure` (structural): Which non-test source files call `analyze_impact`? Is impact analysis reachable from the HTTP REST API?
- `sq-struct-open-callers` (structural): Which non-test source files call `IndexStore::open` (the file-backed constructor, not `open_in_memory`)?
- `sq-struct-relpath-impact` (structural): If the signature of the function `to_relative_string` changes, which non-test source files would need to be updated (its definition and every caller)?
- `sq-struct-search-callers` (structural): Which non-test source files call `RetrievalEngine::search` (the main search entry point)? List every caller file across the CLI, HTTP API and MCP server.
- `sq-struct-transitive-search-symbols` (structural): If `IndexStore::search_symbols` changes behaviour, which non-test source files are affected directly or transitively, up to the user-facing entry points (CLI command, HTTP route, MCP tool)?
- `sq-exact-default-db` (exact): Where is the constant `DEFAULT_DB_NAME` defined, and which files use it?
